# zapret-default-CustomMenu
Простой клиент на С++ для zapret (выбор нужного бат файла с помощью одной клавиши)

## Первый этап, компиляция:

Для что бы скомпилировать репозиторий выполните следующие команды
Для компиляции вам нужно иметь clang последней версии

```bash
git clone https://github.com/xz10101/zapret-default-CustomMenu.git
# Используйте makefile.bat если вы в CMD
# Или makefile.sh если вы в MSYS2
makefile.bat
```
После этого можете запускать программу
`main.exe` либо `./main.exe`
